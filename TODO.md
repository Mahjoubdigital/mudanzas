# Entregables del sitio de mudanzas

- [ ] La página principal presenta una cabecera clara, navegación accesible, marca provisional, CTA de presupuesto y enlaces ancla a las secciones principales.
- [ ] El hero comunica una propuesta de valor directa, usa la imagen aportada como recurso visual, incluye CTAs y se adapta a móvil, tablet y escritorio.
- [ ] La página explica el proceso de mudanza con pasos comprensibles y presenta servicios mediante tarjetas con descripciones en español.
- [ ] El formulario de solicitud de presupuesto valida los campos esenciales, muestra estados de error y confirmación, y deja documentada la integración de destino pendiente.
- [ ] La sección de preguntas frecuentes funciona con acordeón accesible y el footer incluye navegación, contacto y aviso de contenido pendiente de personalización.
- [ ] El proyecto incluye metadatos básicos, manifiesto de rutas, estilos responsive, estados de foco y soporte para reducción de movimiento.
- [ ] Se ejecutan typecheck y build de producción; cualquier integración externa no configurada se indica explícitamente.
